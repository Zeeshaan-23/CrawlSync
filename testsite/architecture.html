CrawlSync Architecture & Design

How CrawlSync coordinates a centralized controller with concurrent worker goroutines and persistent state managers.

System Architecture

CrawlSync employs the classic Producer-Consumer design pattern:

  • Crawler Controller: The centralized scheduler owning the lifecycle state, job dispatch queue, and results processing loop.
  • URL Manager: Mutex-protected state machine maintaining URL statuses (pending, in_progress, completed, failed) and atomic duplicate filtering.
  • Worker Pool: A configurable pool of concurrent worker goroutines that pull jobs, perform HTTP GET requests, parse links, and report results.
  • State Manager: Manages atomic JSON checkpoint creation and resumption.
