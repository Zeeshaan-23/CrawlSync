CrawlSync Operating Systems Testbed

A concurrent web crawler testbed demonstrating multithreading, worker pools, synchronization, atomic persistence, and fault recovery.

Explore OS Concepts in CrawlSync

This test website hosts an interconnected collection of academic articles covering the core Operating Systems principles demonstrated by CrawlSync:

  • Concurrency & Threading: Goroutines, OS threads, worker pools, and CSP message passing.
  • Synchronization Primitives: Mutexes, Reader-Writer locks, critical sections, and atomic operations.
  • URL Management & Traversal: State tracking, deduplication, normalization, and graph traversal.
  • Persistence & Recovery: Atomic checkpoints, crash safety, and uninterrupted state resumption.
  • Networking & HTTP: Connection pooling, SSRF prevention, timeouts, and HTML parsing.

Testing Utilities & Simulated Failure Points

To exercise CrawlSync's error handling and edge cases, this site includes deliberate failure points:

  • Simulated 404 Page (Broken Link) — verifies crawler error handling and failed status recording.
  • Missing Document 404 — secondary missing route for multi-worker error isolation.
  • Complete Sitemap — full directory linking all site pages.
  • Concurrency Benchmarks — worker scalability analysis.
